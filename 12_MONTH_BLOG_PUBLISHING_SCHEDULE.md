## SEO Publishing Checklist

### Pre-Publishing (3 days before)

**Content Preparation:**
- [ ] Write full blog post (2,500-3,500 words)
- [ ] Research and add 10+ external citations
- [ ] Create 1-2 internal links to other calculators
- [ ] Optimize title for keyword (50-60 characters)
- [ ] Write meta description (155 characters)
- [ ] Outline with H2/H3 structure
- [ ] Add featured image (1200x630px, <100kb)
- [ ] Create alt text for all images

**SEO Optimization:**
- [ ] Run through Yoast SEO
- [ ] Target focus keyword in first 100 words
- [ ] Include keyword in H2 and at least 2 H3s
- [ ] Readability: Aim for "Green" (Yoast rating)
- [ ] Check keyword density (1-2% optimal)
- [ ] Verify all links work (broken link check)
- [ ] Add schema markup (Article, FAQPage if applicable)

**Pre-Publish Final Check:**
- [ ] Spellcheck entire post
- [ ] Format numbers and tables clearly
- [ ] Verify all calculator links work
- [ ] Test on mobile device
- [ ] Preview post layout

### Publishing Day

**Scheduling:**
- [ ] Publish at 9:00 AM ET (optimal timing for traffic)
- [ ] Set category (calculator type)
- [ ] Add 3-5 tags (related topics)
- [ ] Pin to homepage (optional for top posts)
- [ ] Add to table of contents page

**Immediate Promotion:**
- [ ] Submit to Google Search Console
- [ ] Share on business social media
- [ ] Add to email newsletter (if weekly)
- [ ] Create tweet/LinkedIn post excerpt
- [ ] Add to "Latest Blog Posts" sidebar widget

### Post-Publishing (Week 1)

**Promotion and Outreach:**
- [ ] Reach out to 3-5 potential backlink sources
- [ ] Share on relevant Reddit communities (no spam)
- [ ] Submit to relevant directories/listings
- [ ] Build internal links from relevant existing posts
- [ ] Email subscribers excerpt + link

**Optimization:**
- [ ] Monitor initial traffic (Google Analytics)
- [ ] Verify indexation (Google Search Console)
- [ ] Check keyword ranking (week 3-4)
- [ ] Adjust if needed based on performance

### Monthly Review (End of Month)

**Performance Analysis:**
- [ ] Review traffic for all posts published this month
- [ ] Identify top performers (share structure for future posts)
- [ ] Identify underperformers (analyze reasons)
- [ ] Update underperforming posts (add content, optimize)
- [ ] Check backlink acquisition
- [ ] Monitor search engine rankings

**Adjustments for Next Month:**
- [ ] Adjust keyword strategy based on rankings
- [ ] Extend top posts with additional content
- [ ] Update evergreen posts with new data
- [ ] Plan based on seasonal trends
