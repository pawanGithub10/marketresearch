### 1.2 Competitor Teardown - Homepage Patterns & Key Insights

#### **OmniCalculator.com** (Benchmark Leader)
- **Homepage Pattern**: Hero section + featured calculator carousel → Category grid (8-12 categories) → Blog/Recent articles → FAQ schema
- **Top 50 Keywords**: "EMI calculator" (search volume: 110K/mo), "age calculator", "percentage calculator", "loan calculator", "SIP calculator", "BMI calculator", "GPA calculator"
- **Most Linked Calculators**: EMI, Loan, Age, Percentage, Discount
- **UX Strengths**:
  - Clean responsive design
  - Single-purpose calculator pages (low cognitive load)
  - Step-by-step input guidance
  - Result sharing + embed capability
  - Mobile-first approach
- **Missing Gaps**:
  - Limited exam-specific (JEE/NEET) calculators
  - No regional language support
  - Limited B2B/teacher tools
  - No worksheet generator

#### **Calculator.net**
- **Homepage Pattern**: Search bar center-top → Top 10 calculators → Category links → Ads integrated
- **UX Weakness**: Cluttered ads; slow loading (Core Web Vitals issue)
- **SEO Gap**: Weak internal linking; poor schema implementation
- **Missing**: Hindi support, exam calculators, mobile optimization

#### **BYJU's Tools** (India competitor)
- **Strength**: India-focused; strong branding; exam calculators (JEE/NEET)
- **Weakness**: High CAC (paid acquisition); limited free content; calculator depth
- **Opportunity**: Calcarena can win with better UX + broader calculator library

#### **RapidTables.com**
- **Strength**: 150+ converters; clean design
- **Weakness**: No Hindi; poor monetization; limited engagement features
- **Opportunity**: Add save/history features; add Hindi versions; better embed strategy

**EMI = [P × r × (1 + r)^n] / [(1 + r)^n - 1]**

- P = Principal amount
- r = Monthly interest rate (annual rate / 12 / 100)
- n = Number of monthly payments
